# `nano-flash`

`nano-flash` is a unified flashing and image construction tool designed for lightweight and microcontroller-based Redox OS deployments (such as ESP32 target profiles).

## Features

- **Multi-Component Packaging**: Bundles the Redox Kernel, Driver HAL, and Ion Shell into a single binary payload with custom header structures.
- **CRC32 Checksum Integrity**: Computes and embeds CRC32 checksums for every component header to ensure corruption-free flashing.
- **Device Flashing Interface**: Provides a CLI command interface for flashing output images directly to device serial ports (e.g., `/dev/ttyUSB0`).

## Installation & CLI Usage

### Build Unified Binary Image

```bash
nano-flash build \
  --kernel /path/to/kernel.bin \
  --hal /path/to/hal.bin \
  --ion /path/to/ion.bin \
  --output nano-esp32.bin
```

### Write Binary Image to Target Device

```bash
nano-flash write --image nano-esp32.bin --port /dev/ttyUSB0
```

## Binary Header Format

Images generated by `nano-flash` begin with a 4-byte magic signature `RDOX` (`0x52 0x44 0x4F 0x58`) followed by a Table of Contents (TOC) array containing 28-byte headers for `kernel`, `hal`, and `ion`.
