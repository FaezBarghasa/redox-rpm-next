# Changelog - redox-bench

All notable changes to the `redox-bench` project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-07-23

### Added
- Initial release of `redox-bench` benchmark suite.
- Integration with `redox-scheme` for microkernel scheme auditing.
- `context-switch` benchmark for measuring process switching cost.
- `network` benchmark module for network stack throughput metrics.
- `memory` residency benchmark.
- `gpu` frame pacing audit module.
- `middleware` overhead benchmark for system scheme wrappers.
- Command-line parser for customizable benchmark execution and iteration control.
